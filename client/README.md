# Nova Pipeline — Client

React + TypeScript frontend for the Nova CG operator workflow.

The app has two tabs:

- **CG Workflow** — live email queue, verification results, discrepancy detail, editable draft reply, approve/send.
- **Query Data** — natural-language questions over persisted pipeline and email audit data.

---

## Prerequisites

| Requirement | Version |
|---|---|
| Node.js | 18+ |
| npm | 9+ |
| Nova server | Running on `http://localhost:8000` |

---

## Setup

```bash
cd client
npm install
cp .env.example .env
```

Edit `.env`:

```env
VITE_API_KEY=your_chosen_api_key
VITE_API_BASE_URL=http://localhost:8000
```

`VITE_API_KEY` must match `API_KEY` in `server/.env`.

---

## Run

```bash
npm run dev
```

Open `http://localhost:3000`.

Production build:

```bash
npm run build
npm run preview
```

## CG Workflow

The queue updates through Server-Sent Events from `/api/v1/pipeline/review-queue/stream`.

Main states:

- **Incoming** — an SU email arrived and the backend is processing attachments.
- **Verification result** — field-by-field match/mismatch/uncertain table with confidence scores.
- **Discrepancy detail** — click a flagged row to view found value, expected value, and source snippet.
- **Draft reply** — right-side email composer generated by the agent; editable before send.

Controls:

- **Email** — reopens the draft/sent email panel after inspecting a discrepancy.
- **Filter** — toggles flagged-only validation rows.
- **Re-run** — reloads the selected thread view; disabled once sent.
- **Accept found value** — resolves a discrepancy by accepting the extracted value.
- **Mark as resolved** — marks a discrepancy as reviewed/resolved.
- **Approve & Send** — submits edited text to the backend; button becomes `Sending...` and then `Sent`.

The selected review panel is not overwritten by live queue updates. A **Load update** banner appears if newer results are available.

## Query Data

The Query tab calls `/api/v1/query` and can answer questions over:

- pending and sent workflow threads
- extracted document fields
- validation results
- sent email subjects/content
- attachment file names
- SMTP delivery metadata stored in `email_audit`

Example questions:

- Show all sent emails with their attachment file names.
- Show everything pending review for customer Brightwave.
- Which shipments had HS code mismatches?
- How many threads were sent today?
